第4章 コンボ集

この章のポイント

  • 基本形は「しゃがみ弱Pを刻んで立ち弱Kから蛇頭鞭（強）締め」です。まずこの形を安定させます
  • 毒状態では蛇頭鞭が毒破裂するようになるため、ラッシュ立ち大Kから蛇頭鞭（中）へ繋ぐルートに切り替えます
  • 締めは状況で使い分け、起き攻め重視なら蛇頭鞭（強）、毒状態や運び重視なら蛇頭鞭（中）です

4-1 最初に覚える基本コンボ

A.K.I.は毒状態によってコンボが変化しますが、最初から複雑なコンボを覚える必要はありません。まずは非毒状態で安定する基本コンボを習得します。

小技始動

しゃがみ弱P
→ しゃがみ弱P
→ 立ち弱K
→ 蛇頭鞭（強）

小技始動の基本形です（ダメージ1266）。刻み数は距離で調整し、密着なら3発まで、中間距離なら2発、遠目なら1発が目安です。しゃがみ弱P同士はつながりますが、立ち弱Kへは目押しになるため、最初はタイミングを体に覚えさせます。

下段から崩した場合は、しゃがみ弱K始動の形を使います。

しゃがみ弱K
→ しゃがみ弱P
→ しゃがみ弱P
→ 蛇頭鞭（強）

中K始動

立ち中K
→ 立ち中P
→ 蛇頭鞭（強）

牽制の立ち中Kが近距離で当たった場合の基本形です。立ち中Kがカウンターヒットした場合は、4-3のルートに切り替えます。

大K始動

立ち大K
→ 悪鬼蛇行
→ 蛇連咬
→ しゃがみ弱P
→ しゃがみ弱P
→ 立ち弱K
→ 蛇頭鞭（強）

差し返しや確定反撃などに使用します。蛇頭鞭（強）で締めると約44Fの有利が取れるため、そのまま起き攻めに移行できます。

4-2 毒状態の基本コンボ

毒状態では蛇頭鞭を当てると毒破裂が起きて相手が崩れるため、追撃の選択肢が増えます。基本形は、小技から蛇頭鞭（強）で毒破裂させ、ラッシュ立ち大Kから蛇頭鞭（中）へ繋ぐルートです。

しゃがみ弱P
→ しゃがみ弱P
→ 立ち弱K
→ 蛇頭鞭（強）
→ ラッシュ立ち大K
→ 蛇頭鞭（中）

立ち強Pのターゲットコンボから入る形もあります。距離が合う場面ではこちらも使えます。

立ち強P
→ 立ち強P（窮奇）
→ 蛇頭鞭（中）

運びを優先する場合は、小技から立ちKを経由して蛇頭鞭（中）へキャンセルするルートが有効です。中央から画面端まで運べます。

しゃがみ弱P
→ しゃがみ弱P
→ 立ち弱K
→ 蛇頭鞭（中）

画面端では、締めの後に蛇軽功で距離を詰めて攻めを継続できます。

ラッシュ立ち大K
→ 蛇頭鞭（中）
→ 蛇軽功（強）

注意点として、小技始動から蛇頭鞭（中）に繋ぐ形は、相手がしゃがみ状態だと蛇頭鞭（中）が当たらない場合があります。その場合は蛇頭鞭（強）の毒破裂ルートを選んでください。

4-3 中P・強P始動コンボ

中Pは近距離で使いやすい始動技です。基本形は次のとおりです。

立ち中P
→ 蛇頭鞭（中）

立ち中Pがカウンターヒットした場合は、悪鬼蛇行派生で運ぶルートに切り替えます。通常ヒットでは繋がらないため、カウンターヒットを確認できた場合に限ります。

立ち中P（カウンターヒット）
→ 悪鬼蛇行
→ 蛇連咬
→ しゃがみ弱P
→ しゃがみ弱P
→ 立ち弱K
→ 蛇頭鞭（強）

立ち中Kがカウンターヒットした場合は、しゃがみ中PからOD蛇頭鞭へ繋ぐルートがあります。

立ち中K（カウンターヒット）
→ しゃがみ中P
→ OD蛇頭鞭
→ 立ち弱K
→ 蛇頭鞭（中）

強P始動では、ターゲットコンボの窮奇を使います。現行の調整では、毒がない状態でも窮奇の2段目が相手をきりもみ状態にするようになり、近距離や画面端では追撃が狙えます。毒状態では毒破裂が起きるため、そのまま蛇頭鞭（中）へ繋げます。

立ち強P
→ 立ち強P（窮奇）
→ 蛇頭鞭（中）

4-4 パニッシュカウンター始動

大Kパニカン

立ち大Kのパニッシュカウンターを確認できたら、強凶襲突へ繋ぎます。約3000ダメージに加えて蛇頭鞭（強）締めの起き攻めまで付く、確定反撃の基本形でもあります。

立ち大K（パニッシュカウンター）
→ 強凶襲突
→ しゃがみ弱P
→ しゃがみ弱P
→ 立ち弱K
→ 蛇頭鞭（強）

下大Kパニカン

しゃがみ大Kのパニッシュカウンターからは、まず蛇頭鞭（中）で締める形が基本です。

しゃがみ大K（パニッシュカウンター）
→ 蛇頭鞭（中）

毒状態の相手には、毒破裂から運ぶルートに切り替えます。

しゃがみ大K（パニッシュカウンター）
→ 蛇頭鞭（中）
→ ラッシュ立ち大K
→ 猛毒牙

弱蛇頭鞭パニカン

弱蛇頭鞭がパニッシュカウンターで当たると相手が崩れるため、ラッシュで拾い直す特殊なコンボが可能です。難度が高いため、最初は無理に習得する必要はありません。

蛇頭鞭（弱）（パニッシュカウンター）
→ ラッシュしゃがみ弱K
→ ラッシュ立ち弱K
→ 蛇頭鞭（中）

毒状態の相手に当てた場合は、蛇頭鞭（中）の毒破裂から、もう一度蛇頭鞭（中）で締める形もあります。

なお、現行の調整ではしゃがみ強Pがパニッシュカウンターで当たると相手を毒状態にできます。毒が付いていない場面では、この一手がその後の毒破裂ルートの起点になります。

4-5 毒破裂コンボと対空

毒破裂後は相手の浮き方が変わるため、始動技や画面位置によって追撃を変えます。代表的な考え方は次のとおりです。

  • 毒破裂後の追撃は、ゲージ消費（ノーゲージ、1ゲージ、2ゲージ）に応じて選択します。基本は1ゲージまでの消費に抑え、蛇頭鞭（強）の毒破裂からラッシュ立ち大K、蛇頭鞭（中）と繋ぐ形が効率に優れます。
  • 猛毒牙で毒破裂させた場合は、ほかの必殺技で毒破裂させた場合と同様のルートを利用しますが、前ステップは入らないため、その場から追撃を組み立てます。
  • 対空で毒破裂させた場合は、相手の高さに応じて追撃を変更します。

対空後の追撃は特に高さが重要です。低い位置で拾った場合は、ラッシュ立ち大Kから蛇頭鞭（中）へつなぎます。真上付近で対空した場合はラッシュ立ち大Kが当たらないため、蛇頭鞭（強）から直接蛇頭鞭（中）へつなぎます。

対空の蛇頭鞭（強）で毒破裂させた場合は、そのまま追撃を伸ばせます。ノーゲージなら蛇頭鞭（中）締め、1ゲージ使えるならラッシュ立ち大Kから猛毒牙で締めて大きく運びます。体力が半分程度の相手には、ラッシュ立ち大KとOD凶襲突を重ねてSA3まで繋ぐリーサルルート（5154ダメージ）も狙えます。

4-6 インパクト返し・確定反撃

インパクト返し後は、大K始動の基本形を使います。4-1の大K始動と刻み数をそろえ、同じ形で統一します。

立ち大K
→ 悪鬼蛇行
→ 蛇連咬
→ しゃがみ弱P
→ しゃがみ弱P
→ 立ち弱K
→ 蛇頭鞭（強）

OD無敵技などをガードした後の確定反撃は、4-4の大Kパニカンの形（強凶襲突から小技刻み）が基本です。ドライブリバーサルをガードした場合は、立ち中Pから蛇連咬へ繋ぐ形も使えます。

立ち中P
→ 悪鬼蛇行
→ 蛇連咬
→ しゃがみ弱P
→ しゃがみ弱P
→ 立ち弱K
→ 蛇頭鞭（強）

相手の体力が少ない場合は、締めの蛇頭鞭（強）からSA3へ繋いで倒し切ります。

4-7 SAを組み込むコンボ

SAはコンボの締めやリーサルに使用します。基本的には、難しいSA2ルートに固執せず、SA1やSA3を利用して確実に倒し切ることを優先します。毒状態の場合は、猛毒牙からSAに繋ぐルートが有効です。非毒状態では、ジャンプ攻撃の後にしゃがみ弱Pを刻んでからSA1やSA2へ繋ぐ方法があります。

倒し切りの目安として、中段の蒲牢から入る、ドライブゲージを全て使うリーサルルートがあります。後半は大K始動の形（悪鬼蛇行、蛇連咬からしゃがみ弱P、弱Pターゲットコンボの渾沌を経由して蛇頭鞭（強））を使います。

ラッシュ蒲牢
→ 立ち中P
→ キャンセルラッシュ立ち大K
→ 立ち中K
→ 立ち中P
→ キャンセルラッシュしゃがみ中K
→ 立ち大K
→ 悪鬼蛇行
→ 蛇連咬
→ しゃがみ弱P
→ 立ち弱P
→ 立ち弱P（渾沌）
→ 蛇頭鞭（強）
→ SA3

ドライブゲージを全て使うルートのため、倒し切れる場面でのみ使用します。締めを弱紫煙砲と紫煙追に変える形も可能です。

4-8 ゲージ消費の使い分け

コンボではダメージだけでなく、ドライブゲージ残量も考慮します。

状況選択
ゲージが1本以上ある毒破裂後にラッシュ立ち大Kを挟むルート（1ゲージ消費が目安）
ゲージを残したいノーゲージの蛇頭鞭（中）・蛇頭鞭（強）締め
画面端へ運びたいラッシュや蛇頭鞭（中）を利用する運搬ルート
毒状態毒破裂後の追撃を優先
バーンアウトが近い高消費コンボを避けてゲージを残す

毒破裂後に2ゲージ以上を使うコンボはドライブゲージの消費が大きく、実戦ではあまり使わないため注意してください。コンボ後の起き攻めに必要なゲージまで考慮して選択します。
