第4章 コンボ集

この章のポイント

  • 最初は非毒状態の基本コンボ（小技刻みから蛇頭鞭（強）締め、大K始動）を安定させます
  • 毒状態では吹き飛び方が変わるため、ラッシュ立ち大Kから蛇頭鞭（中）などの毒破裂ルートに切り替えます
  • 締めは状況で使い分け、起き攻め重視なら蛇頭鞭（強）、毒状態や運び重視なら蛇頭鞭（中）です

4-1 最初に覚える基本コンボ

A.K.I.は毒状態によってコンボが変化しますが、最初から複雑なコンボを覚える必要はありません。まずは非毒状態で安定する基本コンボを習得します。

小技始動

しゃがみ弱P
→ しゃがみ弱P
→ 立ち弱K
→ 蛇頭鞭（強）

小技始動の基本です。距離が近い場合は小技を複数回刻み、遠い場合は刻み数を減らします。

伏せ派生始動

悪鬼蛇行
→ 蛇連咬（K派生）
→ しゃがみ弱P
→ しゃがみ弱P
→ 蛇頭鞭（強）

地上の技を空振りした相手や、近距離での読み合いから狙います。

大K始動

立ち大K
→ 悪鬼蛇行
→ 蛇連咬
→ しゃがみ弱P
→ しゃがみ弱P
→ 蛇頭鞭（強）

差し返しや確定反撃などに使用します。

4-2 毒状態の基本コンボ

毒状態では相手の吹き飛び方が変わるため、追撃の選択肢が増えます。基本となるのは、蛇頭鞭（強）などで浮かせた後にラッシュ立ち大Kから蛇頭鞭（中）へ繋ぐルートです。

立ち弱P
→ 立ち弱P
→ 蛇頭鞭（強）
→ ラッシュ立ち大K
→ 蛇頭鞭（中）

画面端では、締めの後に蛇軽功で距離を詰めて攻めを継続できます。

ラッシュ立ち大K
→ 蛇頭鞭（中）
→ 蛇軽功（強）

運びを優先する場合は、立ち強Kから蛇頭鞭（中）へ繋ぐルートも有効です。

4-3 中P始動コンボ

中Pは近距離で使いやすい始動技です。基本形は次のとおりです。

立ち中P
→ 蛇頭鞭（強）

距離が近い場合や画面端が近い場合は、悪鬼蛇行派生を使って運びを優先します。ただし蛇連咬は発生が遅く、通常ヒットでは繋がらないため、カウンターヒットを確認できた場合に限ります。

立ち中P
→ 悪鬼蛇行
→ 蛇連咬
→ しゃがみ弱P
→ 蛇頭鞭（強）

中央から画面端まで距離がある場合は、キャンセルラッシュや前ステップを利用して運びます。

4-4 パニッシュカウンター始動

大Kパニカン

立ち大Kのパニッシュカウンターを確認できたら、強凶襲突へ繋ぎます。

立ち大K（パニッシュカウンター）
→ 強凶襲突
→ しゃがみ弱P
→ 蛇頭鞭（強）

下大Kパニカン

しゃがみ大Kのパニッシュカウンターからは、毒状態かどうかで追撃を変更します。毒状態の相手には、通常とは異なる追撃ルートを選びます。

紫煙砲（弱）パニカン

紫煙砲（弱）のパニッシュカウンターからは特殊なコンボが可能です。ただし難度が高いため、最初は無理に習得する必要はありません。

4-5 毒破裂コンボ

毒破裂後は相手の浮き方が変わるため、始動技や画面位置によって追撃を変えます。代表的な考え方は次のとおりです。

  • 毒破裂後の追撃は、ゲージ消費（ノーゲージ、1ゲージ、2ゲージ）に応じて選択します。
  • 猛毒牙で毒破裂させた場合は、ほかの必殺技で毒破裂させた場合と同様のルートを利用しますが、前ステップが入らない場合があります。
  • 対空で毒破裂させた場合は、相手の高さに応じて追撃を変更します。

対空後の追撃は特に高さが重要です。高い位置で拾った場合は、立ち中Pから蛇頭鞭（強）へつなぎます。低い位置で拾った場合は、ラッシュ立ち大Kから蛇頭鞭（中）へつなぎます。真上付近で対空した場合はラッシュ立ち大Kが当たらないことがあるため、蛇頭鞭で直接追撃します。

4-6 インパクト返し・確定反撃

インパクト返し後は、相手の体力や状況に応じてコンボを選びます。

立ち大K
→ 悪鬼蛇行
→ 蛇連咬
→ しゃがみ弱P
→ 蛇頭鞭（強）

相手の体力が少ない場合は、締めの蛇頭鞭（強）からSA3へ繋いで倒し切ります。

4-7 SAを組み込むコンボ

SAはコンボの締めやリーサルに使用します。基本的には、難しいSA2ルートに固執せず、SA1やSA3を利用して確実に倒し切ることを優先します。毒状態の場合は、猛毒牙からSAに繋ぐルートが有効です。非毒状態では、ジャンプ攻撃後に小技を刻んでSAへ繋ぐ方法があります。

4-8 ゲージ消費の使い分け

コンボではダメージだけでなく、ドライブゲージ残量も考慮します。

状況選択
ゲージに余裕があるラッシュ立ち大Kを複数回挟む高火力ルート
ゲージを残したいノーゲージの蛇頭鞭（中）・蛇頭鞭（強）締め
画面端へ運びたいラッシュや蛇頭鞭（中）を利用する運搬ルート
毒状態毒破裂後の追撃を優先
バーンアウトが近い高消費コンボを避けてゲージを残す

特に、ラッシュ立ち大Kを複数回使用するコンボはダメージが伸びますが、ゲージ消費も大きくなります。コンボ後の起き攻めに必要なゲージまで考慮して選択します。
